# Contributing

## Propose an improvement

1. Open an issue saying what you would change and why. If you tried it in a cycle, tell us what happened.
2. If you like, send the change as a pull request once the issue has been discussed.

The most useful improvements come from people who ran a cycle: what worked, what didn't, and what you did instead.

Issues and pull requests are welcome in English or Portuguese.

## Register your adaptation

If you adapted the method for your city or institution, add a line to [DERIVATIVES.md](DERIVATIVES.md), by pull
request or in an issue. Your version stays yours, and the record helps other cities find it.

## How versions work

- **One version of the method per six-month cycle**, with what was learned in it.
- Campwe maintains the reference version and decides what goes into it, always explaining the decision in the issue.
- **No version breaks [the rules that don't change](METHOD.md#6-the-rules-that-dont-change).**
- Every version is recorded in [CHANGELOG.md](CHANGELOG.md).
- English is the reference language. The Portuguese translation in [pt-BR/](pt-BR/README.md) follows it.
