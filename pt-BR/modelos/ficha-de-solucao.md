# Ficha de solução

Uma ficha por solução, encontrada em outro lugar ou construída no ciclo. Só os dois últimos campos dependem do lugar.
É isso que deixa a ficha de uma cidade ser encontrada por outra.

| Campo | Pergunta | Resposta |
|---|---|---|
| **Necessidade** | O que as pessoas precisam, sem citar o lugar? | |
| **Princípio** | Qual mecanismo resolve? | |
| **Condições** | Clima, recursos, materiais, renda, infraestrutura, cultura, governo, escala | |
| **Forma local** | Como ficou ali? | |
| **Adoção** | Por que pegou, ou por que não pegou? | |
| **Coordenadas** | Onde, quando, e se surgiu sozinha ou veio de outro lugar? | |

**Origem:** a ficha que esta adapta (link), ou "nova".
**Autores:** quem escreveu esta ficha.
**Fontes:** links de onde a solução está documentada.

---

## Exemplo: o arco

| Campo | Resposta |
|---|---|
| **Necessidade** | Alcançar comida a distância, com segurança |
| **Princípio** | Guardar energia devagar e soltar de uma vez |
| **Condições** | Madeira flexível, fibra para a corda, caça em movimento |
| **Forma local** | O arco de cada povo, com o material de cada lugar |
| **Adoção** | Espalhou-se onde caçar a distância compensava |
| **Coordenadas** | Muitos lugares e épocas |

## Exemplo: esfriar uma rua sem gastar energia cara

Os princípios são sombra, ventilação cruzada e evaporação. O time parte do que já existe e preenche uma ficha para
cada forma:
- uma parede de blocos vazados, que deixa o ar passar e barra o sol, como o cobogó;
- corredores verdes de árvores ao longo de ruas e córregos;
- telhados claros, que refletem o calor.

Depois o time compara as condições de cada ficha com as do seu bairro, antes de adaptar.
